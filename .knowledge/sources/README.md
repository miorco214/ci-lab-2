# Documents de référence (originaux)

Ces cinq documents sont la **référence complète** du projet. Ils ne doivent pas
être modifiés, résumés en place, ni remplacés par les fiches `.knowledge/`.

| Fichier | Contenu |
| --- | --- |
| `The_foundation.docx` | Les couches fondamentales : frontend, API/backend, données, auth, déploiement, qualité. |
| `The_mastery.docx` | Application SaaS/abonnement : dashboards, webhooks, facturation, plans, opérations. |
| `The_industry.docx` | Déclinaisons sectorielles : rôles, intégrations, contraintes spécifiques. |
| `The_Vault.docx` | Sécurité : surface d'attaque, secrets client, XSS, sécurité API, RLS, headers. |
| `The_Pit.docx` | Audits ciblés : admin panel, performance base de données, prompt injection, versioning API, DNS. |

Les fiches de `.knowledge/` en extraient des exigences de construction
« build-first ». Lorsqu'une fiche signale « à vérifier dans les sources »,
revenir ici avant de décider.
